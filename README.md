# **Desenvolvimento de um Sistema de Recomendação de Notícias**

> Este projeto faz parte da Pós Tech - Machine Learning Engineering (FIAP) e tem como objectivo servir como trabalho final para essa pós gradução. 

> O objetivo é desenvolver um sistema de recomendação de notícias utilizando dados reais da Globo. O desafio consiste em prever quais serão os próximos acessos de um usuário no portal G1, garantindo recomendações personalizadas e relevantes.

## **Contexto do Problema**
> Com a grande quantidade de notícias publicadas diariamente, torna-se inviável realizar curadoria manual do conteúdo. Os sistemas de recomendação são fundamentais para melhorar a experiência do usuário, sugerindo notícias com base em seu histórico de navegação e no comportamento de usuários com perfis semelhantes.
---
### **Principais Desafios**
*   Cold-start problem: Como recomendar notícias para novos usuários ou novos conteúdos sem histórico suficiente?
*   Recência: Em um portal de notícias, conteúdos antigos perdem relevância rapidamente.
*   Personalização: Criar recomendações individualizadas para cada usuário com base em seus acessos anteriores.
